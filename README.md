# Guilherme Balestrin — portfólio

Site estático (HTML + CSS + JS puros, sem build). Abra `index.html` ou sirva a pasta (`npx serve .`).

- **Hero:** monitor CRT num mundo arrastável (arraste para olhar em volta; stickers arrastáveis com inércia; 3 cliques rápidos no monitor = "vertical roll"). Estilo ntch.design.
- **Frase por scroll:** reel, caixa de seleção estilo Figma, digitação com cursor, gradiente e letras cromadas 3D. Estilo wowww.art.
- **Seções claras:** janelas de macOS com abas, roda de interesses com balões, serviços, formulário (abre o e-mail), FAQ.
- **PT/EN** (botão no canto, ou tecla `L`) e **modo reduzido** (botão, ou tecla `M`). Teclas `1/2/3` trocam o canal da TV.

## Para personalizar
- E-mail: `CONFIG.email` no topo de `main.js`.
- Textos: objeto `T` (pt/en) em `main.js`.

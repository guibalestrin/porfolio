# Guilherme Balestrin — portfólio

Site estático (HTML + CSS + JS puros, sem build). Abra `index.html` ou sirva a pasta (`npx serve .`).

- **Hero:** claro, no mesmo estilo das seções brancas. Título com marca-texto, foto, notificações reais do Kiwify chegando em sequência (valores do print `assets/kiwify.webp`) e chips. Sem scroll travado; pensado primeiro para o celular.
- **Frase por scroll:** sobe por cima do hero como um cartão e já começa a animar enquanto entra. Reel, caixa de seleção estilo Figma, digitação com cursor, gradiente e letras cromadas 3D. Estilo wowww.art.
- **Seções claras:** janelas de macOS com abas, roda de interesses com balões, serviços, formulário (abre o e-mail), FAQ.
- **PT/EN** (botão no canto, ou tecla `L`) e **modo reduzido** (botão, ou tecla `M`).

## Para personalizar
- E-mail: `CONFIG.email` no topo de `main.js`.
- Textos: objeto `T` (pt/en) em `main.js`.
